# G3 Architects: Responsive Landing Page

A responsive landing page for a **fictional architecture firm**, built as a front-end practice project to strengthen my HTML and CSS layout skills.

🔗 **Live demo:** https://forhadul-wafi.github.io/g3-architects-website/

## About this project

G3 Architects is a practice build, not a real client website. I made it to learn how to structure a full landing page from scratch and make it work across screen sizes. The company, stats, and sponsor logos are placeholders for demonstration only.

## Features

- Navigation bar with Home, About, Contact Us, and Login links
- Hero section with a headline, call-to-action button, and banner image
- Team image gallery
- Feature cards section ("Features you will love & enjoy")
- Stats section (awards, projects, clients, emails)
- Sponsors row
- Fully responsive layout for desktop, tablet, and mobile

## Built with

- **HTML5**: semantic page structure
- **CSS3**: layout, styling, and responsive design with media queries
- **GitHub Pages**: free hosting and deployment

## Project structure

```
g3-architects-website/
├── index.html      # Main page
├── styles/         # CSS files
└── images/         # Banner, team photos, icons, logos
```

## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/forhadul-wafi/g3-architects-website.git
   ```
2. Open the folder:
   ```bash
   cd g3-architects-website
   ```
3. Open `index.html` in your browser.

No installation or build step is needed.
